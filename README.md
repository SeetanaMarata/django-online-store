# 🛍️ Django Интернет-магазин + Блог

Профессиональный интернет-магазин с блогом, разработанный на Django с использованием современных технологий и лучших практик разработки.

### 🏪 Интернет-магазин (Каталог товаров)
- ✅ **Полный CRUD для товаров** (Create, Read, Update, Delete)
- ✅ **Валидация форм** с кастомными правилами:
  - Запрещенные слова в названиях и описаниях
  - Проверка отрицательных цен
  - Валидация загружаемых изображений (формат + размер до 5MB)
- ✅ **Пагинация товаров** (6 товаров на страницу)
- ✅ **Категории товаров** с удобной навигацией
- ✅ **Детальные страницы товаров** с полной информацией
- ✅ **Адаптивный дизайн** на Bootstrap 5 с кастомными стилями
- ✅ **Админ-панель** с фильтрацией и поиском

### 📝 Блог-платформа
- ✅ **Полный CRUD для статей** через Class-Based Views (CBV)
- ✅ **Счетчик просмотров** с автоматическим увеличением
- ✅ **Фильтрация по публикациям** (показываем только опубликованные)
- ✅ **Автоматические редиректы** после редактирования статей
- ✅ **Постраничный вывод** статей

### 🎨 Пользовательский интерфейс
- ✅ **Адаптивный дизайн** (mobile-first подход)
- ✅ **Модульные шаблоны** (базовый шаблон + подшаблоны)
- ✅ **Кастомные CSS стили** с анимациями
- ✅ **Иконки Bootstrap Icons**
- ✅ **Хлебные крошки** для навигации
- ✅ **Валидация форм в реальном времени**

### 🗄️ Модели базы данных
- **Product** (Товар): название, описание, изображение, цена, категория, даты создания/обновления
- **Category** (Категория): название, описание товаров
- **Contact** (Контакты): информация о магазине (адрес, телефон, email)
- **BlogPost** (Статья блога): заголовок, содержание, превью, счетчик просмотров, признак публикации

### 🔐 Валидация и безопасность
- **Запрещенные слова**: казино, криптовалюта, бесплатно, обман и др.
- **Валидация цен**: отрицательные цены не допускаются
- **Валидация изображений**: только JPG/PNG/GIF/BMP/WEBP, максимум 5MB
- **Аутентификация**: CRUD операции доступны только авторизованным пользователям
- **Переменные окружения**: SECRET_KEY и данные БД вынесены в .env файл

## 🛠️ Технологический стек

### Backend
- **Python 3.13** - основной язык программирования
- **Django 5.2** - веб-фреймворк
- **Django ORM** - работа с базой данных
- **Class-Based Views (CBV)** - для блога и CRUD операций
- **Function-Based Views (FBV)** - для главной страницы с пагинацией
- **Django Forms** - с кастомной валидацией

### База данных
- **PostgreSQL** - производственная реляционная БД
- **SQLite** - для разработки (опционально)
- **Django Migrations** - управление схемой БД

### Frontend
- **Bootstrap 5** - CSS фреймворк
- **Bootstrap Icons** - векторные иконки
- **HTML5 + CSS3** - семантическая верстка
- **JavaScript** - минимально для интерактивности

### Инструменты разработки
- **Poetry** - управление зависимостями Python
- **Git + GitHub** - контроль версий
- **GitFlow** - workflow разработки
- **Black + isort** - форматирование кода
- **flake8** - линтинг Python кода
- **mypy** - статическая типизация

### Деплоймент (готово к production)
- **PostgreSQL** настроен через переменные окружения
- **MEDIA файлы** настроены для загрузки
- **STATIC файлы** собраны для production
- **DEBUG режим** зависит от окружения

## 🚀 Быстрый старт

### 1. Клонирование репозитория
git clone <url-репозитория>
cd django_online_store

### 2. Настройка окружения
 #### Установка зависимостей  
poetry install  
 #### Активация виртуального окружения  
poetry shell

#### Настройка переменных окружения
cp .env.example .env   
 Отредактируйте .env файл с вашими настройками
### 3. Настройка базы данных
#### Создание и применение миграций
python manage.py migrate
#### Создание суперпользователя  
python manage.py createsuperuser
#### Загрузка тестовых данных (опционально)
python manage.py create_test_data
### 4. Запуск сервера разработки

python manage.py runserver
### 5. Доступ к приложению
Главная страница: http://127.0.0.1:8000/

Админ-панель: http://127.0.0.1:8000/admin/

Блог: http://127.0.0.1:8000/blog/

Контакты: http://127.0.0.1:8000/contacts/

Тест пагинации: http://127.0.0.1:8000/test-pagination/

## 🛠️ Команды разработки
Основные команды

#### Запуск сервера разработки
python manage.py runserver

#### Создание миграций
python manage.py makemigrations catalog blog

#### Применение миграций
python manage.py migrate

#### Создание суперпользователя
python manage.py createsuperuser

#### Загрузка тестовых данных
python manage.py create_test_data

#### Проверка кода
black catalog blog --check  
isort catalog blog --check-only  
flake8 catalog blog  
mypy catalog blog --ignore-missing-imports  
Кастомные команды

#### Создание тестовых товаров и категорий
python manage.py create_test_data

#### Загрузка данных из фикстур
python manage.py load_test_data  
🔧 Настройка production  
Переменные окружения (.env)  
env  
DEBUG=False  
SECRET_KEY=your-secret-key-here  
DB_NAME=your_database_name  
DB_USER=your_username  
DB_PASSWORD=your_password  
DB_HOST=localhost  
DB_PORT=5432

python manage.py collectstatic
