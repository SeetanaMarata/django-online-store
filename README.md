# 🛍️ Django Интернет-магазин

Профессиональный интернет-магазин, разработанный на Django с использованием современных технологий и лучших практик разработки.

## ✨ Особенности

- 🏪 **Полноценный каталог товаров** с категориями и изображениями
- 📄 **Детальные страницы товаров** с полной информацией
- 📝 **Форма добавления товаров** с валидацией и загрузкой изображений
- 📖 **Постраничный вывод** товаров на главной странице
- 📞 **Динамические контакты** управляемые через админку
- 🎨 **Адаптивный дизайн** на Bootstrap 5 с кастомными стилями
- ⚙️ **Профессиональная админ-панель** с фильтрами и поиском

## 🚀 Функциональность

### ✅ Реализовано
- **Главная страница** - список товаров с пагинацией
- **Страница товара** - полная информация о товаре
- **Страница контактов** - динамические данные из админки
- **Форма добавления товаров** - с валидацией данных
- **Админ-панель** - полное управление товарами, категориями и контактами
- **База данных** - PostgreSQL с миграциями
- **Статические файлы** - кастомные CSS стили
- **Медиа файлы** - загрузка и отображение изображений

### 🔄 В разработке
- Корзина покупок
- Система заказов
- Авторизация пользователей
- Отзывы и рейтинги товаров

## 🛠️ Технологический стек

- **Backend:** Python 3.13, Django 5.2
- **Database:** PostgreSQL
- **Frontend:** Bootstrap 5, HTML5, CSS3, JavaScript
- **Tools:** Poetry, Git, GitHub
- **Code Quality:** Black, isort, flake8, mypy
- **Deployment:** Ready for production deployment

## 📦 Установка и запуск

Клонирование репозитория

git clone <url-репозитория>
cd django_online_store
Настройка окружения
bash
 Установка зависимостей
poetry install

 Активация виртуального окружения
poetry shell

 Настройка переменных окружения
cp .env.example .env
 Отредактируйте .env файл с вашими настройками БД
Настройка базы данных
bash
 Создание и применение миграций
python manage.py migrate

 Создание суперпользователя
python manage.py createsuperuser

 Загрузка тестовых данных
python manage.py create_test_data
Запуск сервера
bash
python manage.py runserver
Доступ к приложению
Главная страница: http://127.0.0.1:8000/

Контакты: http://127.0.0.1:8000/contacts/

Добавить товар: http://127.0.0.1:8000/add-product/

Админ-панель: http://127.0.0.1:8000/admin/

## 🛠️ Команды разработки

 Запуск сервера разработки
python manage.py runserver

 Создание миграций
python manage.py makemigrations catalog

 Применение миграций
python manage.py migrate

 Создание суперпользователя
python manage.py createsuperuser

 Загрузка тестовых данных
python manage.py create_test_data

 Проверка кода линтерами
black catalog --check
isort catalog --check-only
flake8 catalog
mypy catalog --ignore-missing-imports
